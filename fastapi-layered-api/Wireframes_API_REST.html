✏️ Editar Tarea (PATCH Parcial)

✕
🛡️ Verificación de Propietario (BOLA): Tu usuario es el propietario registrado de esta tarea (`owner_id = 1`). Tienes permisos de edición.
💡 Buenas Prácticas UX/UI: La edición parcial (`PATCH`) no obliga al usuario a reescribir campos que no cambiaron. El botón de eliminación (`DELETE`) está separado espacialmente y diferenciado cromáticamente en rojo para evitar clics accidentales (Ley de Hick / Prevención de Errores).
